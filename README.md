# 🚨 Product Recall Analysis

## 📌 Project Overview

This project analyzes product recall data using Microsoft Power BI. The dashboard helps explore product recalls, identify patterns, and understand recall-related information through data visualization.

## 🎯 Project Objectives

- Analyze product recall data.
- Explore recall trends and patterns.
- Understand the distribution of recalled products.
- Identify important information related to product recalls.
- Present insights through Power BI visualizations.

## 🛠️ Tools and Technologies

- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Visualization
- Data Analysis
